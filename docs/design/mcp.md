# MCP 设计

## 已确认范围

M12 交付 stdio 和 Streamable HTTP 工具连接、配置与管理界面、Schema 校验、结果规范化、审批/子任务白名单、取消和资源清理，以及 HTTP 连接的浏览器账号授权。协议基础设施使用 [官方 Python SDK](https://github.com/modelcontextprotocol/python-sdk)，Runtime 保持自行实现。现行字段和生命周期见 [MCP 参考](../reference/mcp.md)。

## 边界与装配

Core 保存连接配置契约，ToolRegistry 提供可选 input_schema 与 parse_arguments 扩展，保持普通 Pydantic 工具行为。Core 不导入 SDK、HTTP 或子进程实现。McpTool 与 McpConnection 位于 adapters，bootstrap 唯一负责具体装配；Server 只持有注入的工具连接工厂与探测回调。

Server 每个 Run 连接已启用服务，再把发现的工具加入父 ToolRegistry。子 Runtime 仍复用同一连接，但构造期按明确子任务白名单过滤，不独立启动进程。直连 CLI 在进程内客户端生命周期持有连接；它是恢复模式，默认 CLI 与 UI 均走 Server。

## 连接所有权

SDK 的 AnyIO task group/cancel scope 要求在同一任务进入和退出，因此每个连接由一个专用任务持有。外部调用经队列交给该任务，业务请求并发执行，取消通过对应 Future 传递到 SDK 请求。关闭先拒绝新调用，排空并取消未结束请求，再退出 session 与 transport。没有自动重试业务调用，避免重复副作用。

每次连接冻结工具目录，名称稳定映射且有服务器来源。MCP 是可选增强，不决定 Run 能否开始：未就绪、连接失败或发现失败的连接只跳过本 Run，并以 `mcp.connection_skipped` 事件记录连接名与安全原因，不静默隐藏缺失工具；修改配置在新 Run 生效，测试时单独建立短连接并在结束后关闭。无数据库变更，连接测试缓存不承担持久化职责。

## 账号授权

浏览器登录由 adapter 内的 OAuth 客户端承担，Core 与 Server 只处理状态。授权期间在本机回环地址启动一次性回调服务：只接受一次带正确 state 与 issuer 的响应，读不到完整请求即超时关闭，结束后立即停止监听。授权地址同时回传界面，浏览器无法自动打开时用户仍可手动完成。

凭据按连接指纹保存在 `~/.nemo/mcp-oauth/` 下的 0600 文件，用同目录临时文件加锁替换。Disconnect 先递增代际再删除，因此授权完成后才到达的写入会被拒绝；指纹包含 URL 与应用标识，改动这些字段即失效旧凭据。一个连接同时只允许一个授权流程，并与 Run、测试共用同一把锁，避免并发刷新或重复注册。

Run、连接测试与直连 CLI 都是非交互的：只使用已保存的令牌、必要时静默刷新，缺少或失效时该连接不进入本 Run 并以事件提示先登录，绝不在后台弹出浏览器。默认动态客户端注册；服务要求预注册应用或 URL 型 client ID 时由配置提供。令牌不进入模型上下文、事件与 Trace。

## 权限与数据

MCP 工具声明属于外部数据，readOnlyHint 不直接决定权限。只读分类由用户配置，子任务使用另设白名单；未知工具在 ask 模式进入现有审批。工具 Schema 在 adapter 校验，禁止解析外部 schema 引用。描述、Schema、结果脱敏，业务结果按 ExecutionContext 输出限额规范化；协议错误和 stderr 不直接暴露。

管理界面采用独立弹窗、左侧简短连接列表和右侧编辑/工具详情。测试已保存配置，不隐式保存表单；凭据只填写环境变量引用。保存、启用与连接测试分别对应明确用户动作，不把测试结果表示成常驻在线状态。

表单先呈现连接信息，再呈现凭据和账号连接；Connect account 紧接凭据设置，减少上下跳转。固定底栏承载保存、测试和启用，右侧表单独立滚动。标题、字段名、输入值与说明使用明确字号和灰度，说明不通过整块透明度降低可读性。低频设置与工具权限折叠，窄窗口切换为单列。

## 验收

OAuth 令牌端点显式协商 JSON；已知兑换失败映射为不含凭据的可执行提示。前端在授权成功后的工具发现返回前保留轮询任务，防止状态变化触发 effect 清理后丢弃发现结果。

HTTP 客户端记录安全的传输/授权失败提示，连接所有者在 SDK 将后台写任务异常转成会话结束时仍可恢复可执行原因。代理继续由显式变量引用决定，不从浏览器或进程隐式推断。

离线 FakeMcpSession 验证类型校验、审批、白名单、错误与凭据边界、超时和清理；Server/CLI 验证装配与 Trace；UI 验证表单、测试反馈、账号授权和权限联动。真实官方 SDK demo 验证 stdio 与 Streamable HTTP 协议；示例授权服务器验证动态注册、PKCE、令牌落盘与免登录复用；实际 loopback TCP 复验验证部署连接、浏览器回调和结束清理。自动化验收不调用收费模型或第三方业务服务。
